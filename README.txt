САЙТ SENTINEL.XYZ
1) Соберите exe: запустите build.bat из архива с исходниками -> out\SENTINEL.XYZ.exe
2) Положите exe в папку downloads\
3) Откройте index.html (или загрузите папку на любой хостинг: GitHub Pages, Netlify, Cloudflare Pages)
Настройки (версия, ссылка, Discord/Telegram) - в файле config.js
